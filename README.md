
# Immersive Weathering

NeoForge port of Immersive Weathering for Minecraft 1.21.1.

## Tested setup

This project has been tested with the following setup:

- Minecraft 1.21.1
- NeoForge 21.1.226
- Moonlight Lib 1.21.1-3.0.5-neoforge
- Java 21

## Requirements

Immersive Weathering requires all of the following:

- Minecraft 1.21.1
- NeoForge
- Moonlight Lib 1.21.1-3.0.5 or newer
- Java 21

If one of these requirements is missing or incompatible, NeoForge should stop loading the mod and show an informative dependency error instead of allowing a later crash.

## Notes

This repository currently targets the NeoForge 1.21.1 environment.
